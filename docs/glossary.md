# Glossary — Multi-Brand Gift Card Wallet

Educational terminology for **gift card wallets and multi-brand gift card programmes**. Labels vary between issuers and aggregators.

## Core Terms

| Term | Definition |
|------|------------|
| **Gift card wallet** | A customer-facing container holding digital gift cards from one or more brands |
| **Multi-brand** | Covering gift cards issued by several different merchants or brands |
| **Issuer** | The brand or processor that holds the card's value and honours redemption |
| **Aggregator** | A provider that connects many brands' gift cards through one API or catalogue |
| **Card vault** | Encrypted storage for gift card codes, PINs, and related metadata |
| **Code reveal** | The act of showing a masked gift card code to the authenticated user |
| **Balance enquiry** | A request to the issuer for the remaining value on a card |
| **Closed-loop card** | A gift card usable only at the issuing brand |
| **Open-loop card** | A network-branded card usable at many merchants |
| **Single-use card** | A card fully consumed in one redemption |
| **Partial redemption** | Using part of a card's value and keeping the remainder |
| **Gift transfer** | Sending a card from one wallet user to another |
| **Re-issue** | Replacing a code with a new one, invalidating the old code |
| **Expiry date** | The date after which the card can no longer be used, where local rules allow |
| **Redemption format** | How the card is presented at checkout: barcode, QR, code, or PIN |
